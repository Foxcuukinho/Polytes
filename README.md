# Polytes V2

## Reescrita do projeto

A **V2 do Polytes está sendo reescrita do zero**.

A V1 foi criada para desenvolver e provar os conceitos fundamentais do projeto: stickmen vivos na área de trabalho, física, ragdoll, personalidade procedural, Utility AI e animação procedural.

Com o desenvolvimento da V1, a arquitetura começou a acumular sistemas e responsabilidades que tornariam a expansão do projeto cada vez mais difícil. Por isso, a V2 não será construída simplesmente modificando a V1. A base está sendo reconstruída desde o início.

A V2 está **apenas no início do desenvolvimento**. Neste momento, a prioridade é reconstruir a base do projeto e sua arquitetura.

Os objetivos, sistemas e planos específicos da V2 ainda serão definidos e documentados.

> **Este README será atualizado futuramente com os objetivos e o escopo da V2 conforme o desenvolvimento avançar.**
