## Safe Desktop Interaction

- [Postponed] Define what the stickman is allowed to do when an action could harm the user's computer or data. Asking for permission was ruled out: it makes him feel like a program with popups, not something alive. Direction to explore: classify each action by what happens if it goes wrong (it can be undone / it loses something the user cannot recover / it disrupts the user right now). Test cases to classify: dragging a desktop icon, closing a window, sending a file to the trash.

---

## Satisfaction-Driven Utility AI

- [New] The brain evaluates available actions using a Utility AI system, taking Maslow's hierarchy of needs into account. Each action receives a score based on how much it is expected to increase the stickman's Satisfaction. The brain then selects the action with the highest score and sets it as the `desired_state`. These evaluations are not always accurate, so the stickman can misjudge how satisfying an action will be.

---

## Maslow-Inspired Action Hierarchy

- [New] Create a hierarchy of needs inspired by Maslow's hierarchy of needs. Actions belonging to higher-priority levels would receive more points in the Utility AI, making them more likely to be selected over actions from lower-priority levels.

---

## Emotion-Reason Balance

- [New] Separate emotion and reason in the brain. When emotion dominates, the Maslow-inspired hierarchy becomes more chaotic, changing the weights of actions in the Utility AI. When reason dominates, the hierarchy becomes more balanced.
